# AI ENGINEERING ATTACHMENT SUMMARY
## Month 1
### Primary Learning
During the first month of the AI engineering curriculum, the primary learning focused on establishing foundational programming skills and understanding the architectural principles behind Large Language Models (LLMs). The coursework introduced fundamental Python programming concepts—including variable assignment, control flow logic, modular functions, dictionary manipulation, and file I/O operations—as the essential toolkit required to build modern AI software. Alongside core coding, the curriculum covered introductory LLM frameworks, explaining how models process prompt inputs, manage context constraints, and interact through API endpoints. To bridge the gap between unstructured model outputs and reliable software systems, significant emphasis was placed on data validation using Pydantic schemas. The training demonstrated that defining strict type hints and data models prevents runtime errors, enforces predictable data structures, and ensures that unstructured text from LLMs can be parsed safely into structured application states.
### Live practical sessions
Through live interactive sessions and hands-on workshops, the focus shifted to practical Natural Language Processing (NLP) fundamentals and the paradigm shift from traditional coding to AI-assisted logic. The instructors illustrated how traditional deterministic algorithms, which rely on rigid rule-based branching, are increasingly augmented or replaced by probabilistic AI workflows capable of interpreting natural language. Students observed how to systematically parse and sanitize input data before feeding it into model pipelines, as well as how to design automated workflows that execute daily repetitive tasks. Furthermore, these workshops covered JSON manipulation techniques to simulate lightweight database operations. By reading, modifying, and serializing JSON files programmatically, the sessions showed how state can be persisted and updated in local applications without requiring heavy relational database overhead.
### Miniprojects and Assignments
The monthly mini-projects provided practical application of these theoretical concepts through real-world software logic. Financial and logic-based assignments included building a Prompt Cost Calculator to compute dynamic API charges based on token counts, alongside a Concert Ticket Pricer and an Expense Splitter designed to handle multi-variable math and user input handling. Organizational and tracking tools were developed, such as a Food Delivery Order Tracker, a Fitness Tracker Dashboard, a Spotify Playlist Sorting Script, and structured JSON parsing workflows, all of which reinforced data cleaning, list sorting, and dictionary state management. For generative applications, a Social Media Bio Generator was constructed to demonstrate controlled text generation through structured prompts. Finally, a machine learning lab introduced practical computer vision via Teachable Machine, where transfer learning concepts were tested by manually tuning hyperparameters—such as learning rates, batch sizes, and epoch counts—to observe model convergence, training stability, and overfitting behavior.

## Month 2
### Primary Learning
During the second month of the curriculum, the learning advanced into complex Retrieval-Augmented Generation (RAG) architectures, token economics, and the mathematical principles underpinning vector embeddings. The coursework detailed how raw natural language is mapped into high-dimensional vector spaces, enabling semantic similarity calculations rather than simple keyword matching. The curriculum explored the operational mechanics of vector databases and indexing frameworks, specifically focusing on Facebook AI Similarity Search (FAISS) for efficient nearest-neighbor retrieval across large datasets. To support these advanced AI architectures, Python programming skills were deepened through advanced language features, including set operations for unique data handling, concise list and dictionary comprehensions, custom decorators for function modifications, and explicit type hinting to maintain high code quality across multi-file projects.
### Live Practical sessions
Live coding sessions and interactive workshops centered on building production-ready, end-to-end embedding pipelines and integrating external knowledge sources into generative language models. Instructors demonstrated secure software engineering practices, such as API key management through environment variables and Google Colab secrets, ensuring sensitive credentials remain isolated from codebase repositories. The sessions illustrated how to connect vector search outputs to LLM prompt windows to ground model generations in factual, retrieved data. Beyond pure technical implementation, workshops addressed professional career development by teaching strategies for optimizing LinkedIn profiles and structuring clean, well-documented GitHub repositories to showcase technical projects effectively.
### Miniprojects
The month’s practical mini-projects allowed for the direct application of vector space mechanics and LLM cost engineering. Hands-on coding assignments included building a foundational vector embedding generation script to transform text into searchable numerical arrays, as well as constructing an interactive Python inspection dashboard to parse, filter, and visualize complex JSON file structures. In a specialized token evaluation lab, token count and API cost comparisons were conducted across three major models—Gemini 2.5 Flash, GPT-4o-mini, and Claude 3.5 Sonnet—by analyzing tokenization efficiency using an excerpt from Daniel Goleman's *Emotional Intelligence*. Finally, the month culminated in an analytical proposal drafting exercise titled AI powered Hybrid RAG system for Samsung manuals which synthesized strategic RAG deployment, prompt engineering, and target audience alignment into a technical project blueprint.
