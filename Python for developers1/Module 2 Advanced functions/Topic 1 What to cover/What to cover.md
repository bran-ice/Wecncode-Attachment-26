 In this module we'll explore how Python treats functions as values you can pass around and store, including short one-line functions called lambdas. We'll use the collection-focused tools map, filter, and sorted to operate on whole lists, learn the parameter forms *args and **kwargs that accept any number of inputs, and see how inner functions can remember the values their outer function had (these are closures). We'll also cover why importing a file runs everything in it and how the __main__ guard keeps a file safe to import. Finally, we'll put those pieces together into a Data Validation Pipeline that composes configurable validators and runs employee records through them.
