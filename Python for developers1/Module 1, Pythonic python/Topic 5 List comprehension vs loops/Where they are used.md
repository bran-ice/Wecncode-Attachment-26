A list comprehension is used When you need a single, clear transformation of every item with an optional filter — for example, extracting and uppercasing all non-empty email local-parts from an API response — a comprehension expresses that in one readable line so the reader sees mapping + filter immediately.
Now let's see where a plain for loop shines. First, when processing uploaded files: if for each file you must validate format, resize the image, save it, and log any warnings, a for loop keeps those multiple statements and side effects clear and in order. Second, when handling streaming sensor readings where you update running aggregates, trigger alerts for out-of-range values, and append each reading to a buffer, a for loop cleanly expresses the sequence of actions for every item.
